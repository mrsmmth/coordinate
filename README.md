# COORDINATE v0.7 TOUCH & GRID

操作性を優先して縦スクロール型へ戻し、MIDI表示とリズム生成を更新した版です。

- ピアノロールをピンチで拡大縮小
- 1本指ドラッグで上下左右へ移動
- ダブルタップまたは「全体表示」でリセット
- 4分／8分／16分／MIXのリズムグリッド
- MIXは演奏案ごとに一つのグリッドを抽選し、途中では変更しない
- 音の長さは全ノートの語尾を一律で伸縮
- 次のコード頭のルート直前で全ノートを停止
- 演奏条件変更時に再生を自動停止
- 大きなパネルとタッチ対象を維持した縦スクロールUI

PWAとして利用する場合はHTTPSまたはlocalhostで配信し、ブラウザからホーム画面へ追加してください。
