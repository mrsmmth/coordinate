# COORDINATE v0.8 CHORD TRIGGER

MIDI表示を確認しながら演奏パラメータを操作できるようにし、16ステップを右手3和音の白玉位置指定へ変更した版です。

- ピアノロールが上部へ追従
- ノブ操作中も生成MIDIを表示
- 16ステップは右手3和音の発音位置としてON/OFF
- 選択位置でルート・3度・5度の3和音を生成
- 未選択位置のランダム右手演奏は単音中心
- 3和音トリガーをピアノロール上でオレンジ表示
- 試聴とFormat 1 MIDIへ同じトリガーイベントを反映
- 音の長さと次ルート直前のノート停止を維持
- ピンチズーム、ドラッグ移動、選択式リズムグリッドを維持

PWAとして利用する場合はHTTPSまたはlocalhostで配信し、ブラウザからホーム画面へ追加してください。
